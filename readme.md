# GradeAssist

GradeAssist is a student-focused grade calculator designed to help students understand their current academic progress and plan for future grades.

## Features

- Calculate current grade averages
- Display letter grades
- Grade Goal Prediction
- Grade Path Planning
- Extra-credit support
- Grades over 100 support
- Academic progress feedback
- Multiple language support
- Dark and light modes
- Larger text accessibility option
- CSV result export
- Desktop teacher-feedback beta
- Android/Kivy version

## Project Versions

GradeAssist currently includes an Android version developed with Python and Kivy and a desktop beta version developed with Python and Tkinter.

The desktop beta is designed for teacher feedback and testing.

## Project Goal

The goal of GradeAssist is to give students an easy-to-use tool for calculating grades, understanding their academic standing, and planning what grades they may need on future assignments.

## Development

GradeAssist is an ongoing software engineering project. New features and improvements are developed and documented through GitHub issues, branches, commits, and pull requests.
